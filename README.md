# Velora Motors — Investor-grade automotive homepage

Next.js 14 + Tailwind CSS + Framer Motion starter based on the supplied automotive product brief.

## Run
```bash
npm install
npm run dev
```

## Hero video
Put a licensed automotive MP4 at `public/hero.mp4`. The page already uses `autoplay muted loop playsInline` with an image fallback.

## Important demo-data note
Inventory, metrics, activity, investor dashboard values and partner/trust signals are demo content. Replace them with verified company data before publishing. Vehicle pricing/specs should be independently verified against the market and exact trim/VIN.
